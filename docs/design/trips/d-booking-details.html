What this shows

  1. The detail sheet for a flight, stay, car, train, cruise, parking and visit, plus a cancelled stay, each with its own fields.
  2. A header with the kind icon, name, subtitle, an always-visible Edit and Close; Confirmation and Address have Copy.
  3. A stay shows Dates only (no check-in or check-out times); Price shows only when costs are shown.
  4. A cancelled stay: a Cancelled badge, struck-through dates and price, and the note Cancelled, so not in the trip's total.
  5. The desktop panel (a stay) over the dimmed trip page.
  6. Replaces the booking card of Trip.svelte; Email, directions, call and the airline app stay hidden once a trip is over.

Booking detail sheet, every kind

A tap on a booking opens a detail sheet: a bottom sheet on phone, a right panel on desktop. The header carries the kind icon, the name, a subtitle, an always-visible Edit and Close; below it is a definition list of the fields that kind has. All seven kinds are drawn, plus a cancelled stay.

Accessible names

  • A dialog named for the booking (Red Rock Lodge); Edit is Edit and always visible; Close is Close. Focus moves into the sheet and returns to the row that opened it; the page behind is inert.
  • Fields are a dl: each label is a dt and each value a dd. Copy buttons are named for what they copy: Copy confirmation code HX81Q, Copy address. A struck-through date or price is read as written, with the note Cancelled, so not in the trip's total beside it.
  • Avatars next to Travellers are decorative: the names are the text.

Tokens and components

  • Sheet bg-popover; header with KindTile (40 px on phone, 44 px on the panel), the name in text-lg font-semibold, a muted subtitle (Stay · Moab, UT), Edit and Close. The cancelled badge is the red status chip (--status-bad-*).
  • Labels are eyebrow; values are text-base font-medium and right-aligned; the confirmation code is Geist Mono. Desktop is a 460 px right panel with the page dimmed.
  • Fields come from Segment.details as PassCard.svelte lists them: flight (Terminal, Seat, Cabin), stay (Address, Room), car (Car, Pick-up address), parking (Address, Space, Vehicle, Notes), cruise (Ship, Cabin, Deck), others (Seat, Cabin). Where the mockup's label differs from PassCard's (Class, Pick-up, Ports, Drop-off), the build issue settles the name.

Replaces and what stays hidden

  • The booking card in Trip.svelte (PassCard with its footer): the same facts, moved into a sheet, with Edit always visible instead of under More options.
  • Once a trip is over, Email, Directions, Call and the airline app stay hidden, as Trip.svelte does today (over). Gate and live flight status are not drawn for the same reason.
  • A stay shows Dates, with no check-in or check-out times. Price shows only when costs are shown. A cancelled booking keeps its fields and says it is not in the total.
  • Edit's place (here, in the sheet) and the flight and train fields not drawn are open questions 5 and 6.
  • Owner decision, 2026-11-17 (#712): the frames draw no More, but Move and Remove, which the booking card had under More, stay reachable as a More menu beside Edit in the header (Edit always visible, Close as drawn).
