MapKit only: Stats map

How the Stats world map looks and loads on MapKit, at phone width (390 px) and desktop width (1280 px; the 960 px content column). Drawn with Waypoint’s tokens (frontend/src/app.css), dark only. Apple’s map is a stylised stand-in (a real tile can’t be committed); the yellow tags are notes for the reader, not part of the app. Every name and place is made up. See the README for the inventory, privacy statement and build plan.

b

The Stats map on a live MapKit map

One live MapKit map replaces TravelMap.svelte in #stats-map-slot: Apple’s dark style with points of interest off, airports as dots sized by visits (--map-airport), flights as great-circle lines whose width follows the number of flights (--map-route), stays as small pins (--map-stay), fitted to the period’s places as today. MapKit’s own zoom control replaces Waypoint’s buttons. Visited countries and states are not shaded (MapKit has no country shapes; keeping the bundled outlines is README question 2); the tiles and the countries list carry it.

Interaction

  • Phone: one-finger drag scrolls the page until the map is zoomed in with + (then it pans), as today’s map pans only when zoomed in. Desktop: drag pans, the wheel zooms.
  • A tap selects an airport, a route or a stay and fills the caption under the map (b2).

Accessible names

  • The map is role="img", named Map of the flights, airports and stays; the caption is a polite live region; the countries list is the same information as text.

What Apple is sent

  • The tiles of the area on screen and of every area the viewer pans or zooms to. Apple’s script is handed the period’s airports, arcs and stays to draw.
b2

A tapped airport, and loading

A tap shows the place and each of its trips with dates under the map, as today. While MapKit and the first tiles load, the slot shows today’s skeleton (Loading the map, h-56, pulsing unless reduced motion).

b3

No key, or the map fails

With no key the section keeps its heading, the tiles and the lists; there is no map slot and no skeleton, so nothing appears and then disappears. If MapKit fails to load, refuses its token or errors later, the slot collapses to this.

Rule

  • The slot exists only while app.state.mapkit is true and the viewer is online; a failure removes it. No message.
