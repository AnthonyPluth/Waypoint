Arriving near a booking: the Settings switch

The Arrival codes card in Settings, Offline & notifications, inside the iPhone app, and every state it can be in, with the permission steps. Phone width only, dark only, vector only. Uses only existing tokens and the card, row, switch and chip of the Offline access card. Every place and time is made up.

C0

In place: Settings, Offline & notifications

A new card, only inside the iPhone app, directly below Offline access and above the reminders. In a browser there is no card at all (browsers can’t watch places). It is off until the person switches it on and allows location.

C1

Switching it on: the permission steps

Switching on asks iOS for location (the system alert shows Waypoint’s purpose line) and then for notifications. Choosing Allow While Using App gives the in-app card (A3). iOS later offers, by itself, to change to Always, which adds the notification (A1). The app never asks twice: after a refusal the card points to iOS Settings.

C2

On

The card names the places it is watching (the app is open and unlocked, so names are fine here) and says when each stops.

C3

When something is missing

Each state says what is missing in plain words and, where iOS holds the answer, offers Open iOS Settings. The switch stays on, so the feature starts working as soon as the missing piece is allowed; switching it off stops everything.
