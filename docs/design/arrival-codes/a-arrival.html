Arriving near a booking: the notification and the banner

What the iPhone app shows when you arrive near a parking lot, a rental pickup or (if the owner keeps it) a hotel on a saved trip. Phone width only, dark only, vector only. The iOS lock screen, banner and alerts are drawn only to place Waypoint’s parts: their look is Apple’s. Every place, code and time is made up.

A1 LockedA2 In useA3 App open? Open questions
A1

The notification, phone locked

With Always location and notifications allowed, arriving inside a booking’s circle during its window posts one local notification. Passive: no sound, no badge, no vibration, never on the lock screen with a code. Recommended wording names the kind only, so the lock screen and the small file the app reads while locked carry no place, name or code. Tapping it opens the code after Face ID or the passcode (C).

A2

The notification, phone in use

The same notification as a banner while another app is open. It disappears by itself after a few seconds and stays in Notification Centre until the booking’s window ends, when the app removes it.

A3

Opening Waypoint near the place

With While Using (or Always) location, opening or returning to the app inside a booking’s circle during its window puts one card at the top of Upcoming. The app is unlocked and open, so the card names the place. One card at a time: the booking whose window started last. Dismiss hides it for that arrival; it does not come back until you leave and arrive again. It never opens the code by itself (an alternative for the owner, question 3).

Open questions for the owner

Nothing here is signed off. The README answers each of #819’s six points with a recommendation and lists what each booking holds today.

  1. Which kinds? Parking and rental pickup as recommended? Keep hotels? Confirm flights are left out.
  2. May the iPhone app keep the parking QR picture with the saved trips, so it comes up with no connection? Today it is never on any device. If no, B2 is what you see offline.
  3. Opening the app near the place: a card with one tap to the code (recommended, A3), or open the code straight away?
  4. Finding the places: the phone sends each booking’s address (never its location) to Apple’s geocoder once per save (recommended), or the server’s postcode-level points (often a kilometre off), or airport bookings only?
  5. Lock screen wording: kind only (recommended, A1a) or the place’s name (A1c)?
  6. Windows and radii: the defaults in the README, including a second notification for a parking exit?
  7. The card: “Arrival codes”, “Bring up codes when I arrive”, below Offline access, off after sign-out, with two privacy lines?
  8. Turning it off deletes the derived arrival file and coordinates but no trip: is that what #819 means by “deletes nothing”?
