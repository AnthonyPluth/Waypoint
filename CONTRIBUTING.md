# Contributing

- [Development](https://anthonypluth.github.io/Waypoint/contributing/development/) covers setting up a checkout and running the checks; `make check` runs everything CI runs.
- AI coding agents start from [AGENTS.md](AGENTS.md), and an issue for one uses the "Agent task" template.
- To report a vulnerability, follow [SECURITY.md](SECURITY.md) rather than opening an issue.
- The repository is public: keep names, codes, numbers and itineraries from anyone's real travel or mail out of issues, pull requests and fixtures.
